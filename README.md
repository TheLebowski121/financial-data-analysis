# Financial Data Analysis

A Python-based financial data analysis project focused on acquiring, processing, and analyzing stock market and company financial data.

## Project Overview

This project documents my progress learning Python for financial analysis, with applications in investment research, portfolio analytics, and financial modeling.

The initial version uses Apple (AAPL) as a case study to explore financial data acquisition and fundamental analysis.

## Current Features

- Download historical stock market data using `yfinance`
- Analyze stock prices and calculate daily returns
- Retrieve company financial statements
- Examine dividends, stock splits, and institutional ownership
- Calculate year-over-year revenue growth
- Calculate net profit margins and free cash flow margins
- Display financial results in organized terminal sections
